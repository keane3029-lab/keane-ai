# 🤖 keane-ai

An uncensored AI chat application that runs directly inside your terminal, powered by OpenRouter. 

## 🚀 Features
* **Terminal Native:** Chat with AI seamlessly without ever leaving your command line.
* **Uncensored Conversations:** Flexible, raw, and unfiltered AI processing.
* **Multi-Platform:** Built to run beautifully on Windows, macOS, Linux, and Android (Termux).

---

## 📦 Installation & Usage

You don't even need to download the source code to run it! Because it is live on the global npm registry, you can execute it instantly.

### 💻 Windows / macOS / Linux
Open your terminal or command prompt and run:
```bash
npx keane-ai
📱 Android (Termux)
Bring your AI chatbot on the go! Open Termux and set up Node.js first:

Bash
pkg update && pkg install nodejs -y
Once installed, launch the app directly:

Bash
npx keane-ai
🛠️ Local Setup & Development
If you want to clone the repository, tweak the code, or experiment with the logic locally:

Clone the repository:

Bash
   git clone [https://github.com/keane3029-lab/keane-ai.git](https://github.com/keane3029-lab/keane-ai.git)
   cd keane-ai
Install dependencies:

Bash
   npm install
Configure your API Key:
Create a .env file in the root directory and drop your OpenRouter key inside:

Code snippet
   OPENROUTER_API_KEY=your_api_key_here
Run it locally:

Bash
   node index.js
