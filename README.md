# 🤖 keane-ai

An uncensored AI chat application that runs directly inside your terminal, powered by OpenRouter.

## 🚀 Features
* **Terminal Native:** Chat with AI without ever leaving your command line.
* **Uncensored Conversations:** Flexible and unfiltered AI responses.
* **Powered by OpenRouter:** Connects smoothly to top-tier language models.

## 📦 Installation

You don't even need to download the source code to run it! Since it's live on npm, anyone can launch it globally using `npx`:

```bash
npx keane-ai
